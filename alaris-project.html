ALARIS Lab

Technologies: UR10, ROS, MoveIt, OpenCV, PCL

Integrated vision-based object detection with UR10 robotic-arm control, point-cloud processing, camera-to-robot frame transformation, and inverse kinematics using MoveIt.

  • Object detection with voxel-grid filtering and cluster extraction
  • Trajectory planning using inverse kinematics
  • Related: anthropomorphic hand teleoperation (prosthesis project)
